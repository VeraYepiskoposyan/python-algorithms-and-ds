# Python Algorithms & Data Structures Practice

This repository contains **67 Python implementations** of core data structures, foundational algorithms, and LeetCode-style problem-solving tasks.

##  Topics Covered

- **Array & String Manipulation:** Two Pointers, Sliding Window, Run-Length Encoding, Prefix Sums.
- **Hash Tables / Dictionaries:** Frequency Counters, Complement Lookup (Two Sum), Categorization.
- **Data Structures:** Stacks, Sets, Min-Heaps (`heapq`), 2D Matrices.
- **Algorithmic Strategies:** Binary Search, Sorting, In-place Array Mutations.
